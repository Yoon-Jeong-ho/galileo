# MDK12-Bench: A Multi-Discipline Benchmark for Evaluating Reasoning in Multimodal Large Language Models

- Year: 2025
- Venue: arXiv
- Authors: Pengfei Zhou, Fanrui Zhang, Xiaopeng Peng, Zhaopan Xu, Jiaxin Ai, Yansheng Qiu, Chuanhao Li, Zhen Li, Ming Li, Yukang Feng, Jianwen Sun, Haoquan Zhang, Zizhen Li, Xiaofeng Mao, Wangbo Zhao, Kai Wang, Xiaojun Chang, Wenqi Shao, Yang You, Kaipeng Zhang
- URL: https://arxiv.org/abs/2504.05782
- BibTeX key (if we add it): mdk12bench_zhou_2025
- Tags: multimodal, benchmark, reasoning, k12, contamination

## One-sentence takeaway

A large-scale K-12 exam–derived multimodal reasoning benchmark (140K instances, 6 disciplines) plus a dynamic evaluation protocol aimed at reducing test-set contamination via bootstrapped variations.

## What problem does it solve?

- Multimodal LLM (MLLM) reasoning evaluation is often narrow (few domains), small, and weakly structured.
- Benchmarks can be vulnerable to contamination (memorization / overlap with training data), making reported scores unreliable.

## What is the core method / protocol?

- **Dataset/benchmark:** MDK12-Bench, built from real-world K-12 examinations.
  - Disciplines: math, physics, chemistry, biology, geography, information science.
  - Scale: ~140K “reasoning instances” across grade/difficulty levels.
  - Added structure: instance-level knowledge-point annotations (6,827 knowledge points), difficulty labels, answer explanations, and cross-year partitions.
- **Dynamic evaluation framework (anti-contamination):** during evaluation, *bootstrap* variations of
  - question forms,
  - question types,
  - image styles,
  to reduce exact-match memorization advantages.

## What are the key metrics?

- Standard benchmark performance metrics per task (primarily accuracy / score on exam-style questions), stratified by:
  - discipline,
  - difficulty / grade level,
  - (claimed) dynamic-eval variants and cross-year partitions.

## What are the main results?

- Authors report that “current MLLMs” show **significant limitations** on MDK12-Bench.
- Dynamic evaluation is proposed as a mitigation for contamination effects (details would be in the full paper).

## How is this similar to GALILEO?

- Shared theme: **robust evaluation protocols** that don’t overfit to a fixed test set.
- The dynamic evaluation idea is adjacent to GALILEO’s likely need for *protocol-level robustness* (e.g., variant generation, turn/format perturbations, contamination resistance).

## How is this different from GALILEO?

- Focuses on **multimodal exam-style reasoning**, not multi-turn interaction dynamics.
- Primary failure modes are likely **reasoning + perception** (and contamination), rather than conversational drift / susceptibility / social pressure.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO targets multi-turn interaction robustness, it covers dynamics (drift, compounding errors, recovery) that static exam benchmarks don’t capture.

## Where GALILEO is weaker / needs to improve

- Anti-contamination: MDK12 explicitly bakes in a **dynamic evaluation** concept; GALILEO may need a similarly explicit contamination-resilient evaluation story (e.g., templated variant generation with held-out paraphrase/format families).
