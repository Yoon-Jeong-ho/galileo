# PersoDPO: Scalable Preference Optimization for Instruction-Adherent, Persona-Grounded Dialogue via Multi-LLM Evaluation

- Year: 2026 (accepted WISE 2025)
- Venue: arXiv / WISE 2025
- Authors: Saleh Afzoon; MohammadHossein Ahmadi; Usman Naseem; Amin Beheshti
- URL: https://arxiv.org/abs/2602.04493
- BibTeX key (if we add it): PersoDPO2026
- Tags: persona, dialogue, preference-optimization, multi-turn

## One-sentence takeaway

PersoDPO builds DPO preference pairs automatically by scoring dialogue responses from multiple LLMs (open + closed) on persona/coherence + instruction/format compliance, improving persona-grounded multi-turn dialogue without human labels.

## What problem does it solve?

- Open-source instruction-tuned LLMs can be fluent but still fail at (i) multi-turn contextual coherence and (ii) aligning responses to persona cues in persona-grounded dialogue.
- Human preference labeling is expensive; the paper aims for scalable, reproducible supervision signals.

## What is the core method / protocol?

- Generate candidate responses for the same dialogue contexts using a set of LLMs (both open- and closed-source).
- Automatically evaluate each response with multi-aspect metrics targeting:
  - contextual coherence (multi-turn grounding),
  - persona alignment / personalization,
  - instruction adherence via a length/format compliance feature (to keep outputs machine-consumable in pipelines).
- Combine these scores to form preference pairs (chosen vs rejected) without manual annotation.
- Fine-tune an open-source instruction-tuned model with Direct Preference Optimization (DPO) on these automatically-constructed pairs.

## What are the key metrics?

- Automatic evaluation metrics for:
  - coherence across turns,
  - persona alignment / personalization,
  - length/format compliance (instruction adherence proxy).
- The paper situates itself relative to persona dialogue evaluation frameworks (e.g., PersoBench) and reports multiple evaluation dimensions on FoCus.

## What are the main results?

- On the FoCus dataset, a model trained with PersoDPO outperforms:
  - strong open-source baselines, and
  - a “standard DPO” variant,
  across multiple evaluation dimensions (coherence, personalization, and instruction adherence).

## How is this similar to GALILEO?

- Uses an explicit *multi-metric evaluation signal* (not just next-token likelihood) to create supervision for improving multi-turn conversational behavior.
- Leans on “judge” signals (automatic evaluation; plus the idea of leveraging stronger/closed models’ behavior) rather than human labels.

## How is this different from GALILEO?

- Focus is persona-grounded dialogue quality (coherence + personalization + formatting), not robustness to social pressure / sycophancy / belief drift.
- Optimization target is improving a dialogue generator via DPO; not primarily an evaluation benchmark/protocol for pressure-driven failure modes.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO provides controlled *pressure vs evidence* manipulations and trajectory metrics (flip/recovery/survival-style), that would be a clearer diagnostic lens than PersoDPO’s aggregate auto-metric scoring.

## Where GALILEO is weaker / needs to improve

- PersoDPO is a concrete example of an *annotation-free preference-pair pipeline* using automatic evaluators + multi-model response pools; GALILEO could be asked “how would you train against your benchmark?” and this is one plausible recipe.
