# Free-MAD: Consensus-Free Multi-Agent Debate

- Year: 2025
- Venue: arXiv
- Authors: Yu Cui; Hang Fu; Haibin Zhang; Licheng Wang; Cong Zuo
- URL: https://arxiv.org/abs/2509.11035
- BibTeX key (if we add it): FreeMAD2025
- Tags: multi-agent, debate, anti-conformity, robustness, aggregation

## One-sentence takeaway

Free-MAD argues that multi-agent debate can work better (and cheaper) without consensus by (i) adding an explicit anti-conformity debate mode and (ii) selecting answers via a score that uses the whole debate trajectory instead of last-round majority vote.

## What problem does it solve?

- Standard multi-agent debate pipelines often aim for consensus over multiple rounds and pick the final answer with last-round majority voting.
- This creates (a) token/latency overhead from multi-round interaction, (b) error propagation from LLM conformity (correct agents get pulled toward incorrect majority), and (c) randomness / unfairness from majority vote (and brittleness under attacks / compromised agents).

## What is the core method / protocol?

- “Consensus-free” debate protocol with two changes:
  - Debate-stage modification: introduce an explicit *anti-conformity* mode (alongside conformity) that pushes agents to look for flaws in others’ reasoning rather than aligning with majority.
  - Decision-stage modification: replace last-round majority vote with a *score-based* decision mechanism that evaluates the *entire debate trajectory* (intermediate outputs across rounds), tracking how each agent’s reasoning evolves.
- The paper also claims a formalization (“syntax for the MAD protocol”) to analyze/compare Free-MAD with prior MAD variants.

## What are the key metrics?

- Reasoning accuracy on benchmark QA / reasoning datasets (8 datasets; spans knowledge-based, logical, and mathematical reasoning).
- Token cost / scalability proxy via number of debate rounds (they emphasize single-round debate).
- Robustness under “real-world attack scenarios” (details not captured from the truncated HTML extract; likely prompt injection / compromised agents / comms attacks).

## What are the main results?

- Improves reasoning performance versus existing MAD approaches while using fewer rounds (claimed single-round debate), reducing token cost.
- More robust in attack scenarios than consensus + majority-vote MAD.

## How is this similar to GALILEO?

- Both are concerned with *multi-agent* reasoning quality and failure modes arising from interaction dynamics.
- Both emphasize robustness (e.g., against manipulation/attacks) and a more reliable aggregation/selection mechanism than naive majority vote.

## How is this different from GALILEO?

- Free-MAD is positioned specifically as a *debate protocol* optimization (debate-stage prompting + decision rule) rather than a broader end-to-end agent architecture.
- Their decision rule is “score the whole trajectory” (within a debate) whereas GALILEO may instead emphasize different sources of signals (e.g., environment feedback, tool-based verification, or structured evaluation) depending on the paper.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO has externally verifiable checks (tools, constraints, execution, retrieval grounding), that can be a cleaner correctness signal than purely text-trajectory scoring.
- If GALILEO supports modular policies (separating generation vs critique vs verification), it may generalize beyond debate-style tasks.

## Where GALILEO is weaker / needs to improve

- If GALILEO currently relies on consensus/majority-like aggregation at any stage, Free-MAD is a concrete citation for why that can be brittle under conformity and attacks.
- If GALILEO lacks explicit mechanisms to counter social/conformity pressure among agents, Free-MAD’s “anti-conformity mode” is a relevant design knob.
