# EduDial: Constructing a Large-scale Multi-turn Teacher–Student Dialogue Corpus

- Year: 2025
- Venue: arXiv
- Authors: Shouang Wei, Min Zhang, Xin Lin, Bo Jiang, Zhongxiang Dai, Kun Kuang
- URL: https://arxiv.org/abs/2510.12899
- BibTeX key (if we add it): edudial2025
- Tags: multi-turn, dataset, tutoring, education, evaluation

## One-sentence takeaway

EduDial is a large synthetic multi-turn teacher–student dialogue dataset (34k sessions across 345 knowledge points) plus an 11-dim rubric-style eval framework and a 32B model fine-tuned to improve “student-centered” teaching behaviors.

## What problem does it solve?

- General multi-turn benchmarks don’t measure domain-specific *teaching* skills (timely questioning, adapting strategy across stages, scaffolding to student level).
- Existing educational dialogue datasets are limited by cost (human annotation) or by rigid prompting that ignores student cognitive differences.

## What is the core method / protocol?

- Data construction via **teacher and student agents** interacting to generate multi-turn teaching sessions.
- Design is guided by **Bloom’s taxonomy** and a **five-stage** teaching process (intro → concept exploration → deep understanding → application → reflection).
- Incorporates **10 questioning strategies** (examples mentioned: situational, ZPD, metacognitive questioning).
- Differentiated student strategies: students at different cognitive levels; the teacher adapts questioning and pacing.
- Build EduDial-LLM (32B) via training on the dataset; mentions preference optimization (e.g., DPO) in the paper’s pipeline description.

## What are the key metrics?

- An **11-dimensional evaluation framework** intended to score teaching ability, covering:
  - overall teaching quality
  - content quality
- (Paper evaluates 17 mainstream LLMs using this rubric; details of each dimension would be worth extracting if we later cite it.)

## What are the main results?

- Across 17 mainstream LLMs, most models “struggle” in **student-centered** teaching scenarios.
- EduDial-LLM 32B reportedly achieves **consistent gains** and outperforms baselines **across all metrics** in their framework.

## How is this similar to GALILEO?

- Shares the **multi-turn evaluation** theme: capabilities emerge/fail over a sequence, not a single prompt.
- Uses a structured *protocol* (stages/strategies) that resembles “interaction design” rather than static test sets.

## How is this different from GALILEO?

- Focus is pedagogical dialogue quality, not robustness to social pressure / belief drift / sycophancy.
- Emphasizes dataset construction + teaching rubric; less about adversarial perturbations, turn-of-failure, or stability metrics.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO targets robustness/stability, it likely uses clearer counterfactual conditions (e.g., pressure vs no-pressure) and explicit *failure-time* style metrics—whereas EduDial is largely rubric-based teaching quality.

## Where GALILEO is weaker / needs to improve

- If GALILEO includes “instructional” or “assistant coaching” settings, EduDial’s stage/strategy scaffolding could provide more realistic educational interactions.
