# Multi-IF: Benchmarking LLMs on Multi-Turn and Multilingual Instructions Following

- Year: 2024
- Venue: arXiv
- Authors: Di Jin*, Chaoqi Wang*, Chloe Bi, Karishma Mandyam, Hejia Zhang, Chen Zhu, Ning Li, Tengyu Xu, Hongjiang Lv, Shruti Bhosale, Chenguang Zhu, Karthik Abinav Sankararaman, Eryk Helenowski, Melanie Kambadur, Aditya Tayade, Hao Ma, Han Fang, Sinong Wang, Yun He
- URL: https://arxiv.org/abs/2410.15553
- BibTeX key (if we add it): multiif_jin2024
- Tags: multi-turn, instruction-following, multilingual, benchmark

## One-sentence takeaway

Multi-IF extends IFEval into a **3-turn, 8-language** benchmark with verifiable constraints, showing instruction-following accuracy degrades substantially with turn depth and more in non-Latin scripts.

## What problem does it solve?

- Existing instruction-following benchmarks are mostly **single-turn** and **English-only**, missing real deployment conditions (multi-turn + multilingual).
- Evaluation is hard when instructions are subjective; Multi-IF focuses on **verifiable instructions** to enable objective checking.

## What is the core method / protocol?

- Start from IFEval (verifiable constraints).
- Convert each prompt into a **3-turn conversation** by sampling/revising/expanding prompts.
- Filter out **conflicting instructions** across turns using an LLM-based filter plus human audit.
- Translate English prompts into **7 additional languages** (French, Russian, Hindi, Italian, Portuguese, Spanish, Chinese) with LLM translation + professional human audit.
- Dataset size: **4,501 multilingual conversations**, each with **3 turns**.

## What are the key metrics?

- Turn-level instruction-following accuracy (average across languages / across turns).
- Per-language breakdown (notably higher error rates for non-Latin scripts).

## What are the main results?

- Multi-IF is meaningfully harder than IFEval; performance drops with each additional turn.
- Example reported in the paper: **o1-preview** drops from **0.877 (turn 1)** to **0.707 (turn 3)** in average accuracy across languages.
- Non-English performance is consistently worse; **Hindi/Russian/Chinese** (non-Latin scripts) show higher error rates.
- Authors note stronger reasoning can help recover from earlier-turn mistakes, but models also “forget” previously satisfied constraints as turns accumulate.

## How is this similar to GALILEO?

- Same broad theme: **multi-turn degradation** and the importance of tracking *when* failures occur, not just whether they happen.
- Provides an adjacent empirical anchor that multi-turn settings systematically erode compliance even on objectively checkable constraints.

## How is this different from GALILEO?

- Multi-IF is about **instruction-following compliance**, not belief drift / persuasion / sycophancy.
- Fixed short horizon (3 turns), no survival/censoring framing, and no explicit pressure vs evidence controls.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO reports time-to-failure / trajectory patterns under pressure, it captures richer *dynamics* than a 3-turn compliance benchmark.

## Where GALILEO is weaker / needs to improve

- Multilingual + non-Latin-script robustness: Multi-IF suggests large gaps that could confound generalization claims if GALILEO remains English-only.

## Action items for GALILEO (experiments / method / writing)

- [ ] Consider a small multilingual slice (even 2–3 languages) to test whether multi-turn robustness effects are language-dependent.
- [ ] In related work, cite Multi-IF as evidence that **multi-turn evaluation surfaces failures hidden in single-turn tests**, even for verifiable constraints.
