# MedPI: Evaluating AI Systems in Medical Patient-facing Interactions

- Year: 2026
- Venue: arXiv
- Authors: Diego Fajardo V.; Oleksii Proniakin; Victoria-Elisabeth Gruber; Razvan Marinescu
- URL: https://arxiv.org/abs/2601.04195
- BibTeX key (if we add it): medpi2026fajardo
- Tags: multi-turn, medical, patient-facing, evaluation, rubric, llm-as-judge, simulated-patient

## One-sentence takeaway

MedPI is an OSCE/ACGME-inspired, **105-dimension** rubric benchmark that uses **LLM patients + committee LLM judges** to evaluate multi-turn patient–clinician conversations at scale.

## What problem does it solve?

- Existing medical LLM evaluation is dominated by single-turn QA (MedQA/MedMCQA/etc.), which misses multi-turn clinical interaction skills (eliciting info, managing uncertainty/affect, safety).
- Prior multi-turn patient-simulation / evaluation work often has (per the paper) **coarse rubrics**, unnatural patient behaviors (too cooperative / reveals info early), and no reusable end-to-end pipeline.
- Human standardized-patient OSCE-style evaluation is realistic but operationally expensive and hard to run continuously while iterating.

## What is the core method / protocol?

- Five-layer evaluation stack:
  1) **Patient Packets**: synthetic EHR-like “ground truth” patient records.
  2) **AI Patient**: an LLM agent grounded in the packet with **memory + affect**.
  3) **Task Matrix**: encounter reason × objective (e.g., anxiety/pregnancy/wellness × diagnosis/lifestyle/medication advice).
  4) **Evaluation Framework**: **105 dimensions**, each scored 1–4, mapped to **ACGME competencies/milestones**.
  5) **AI Judges**: calibrated, committee-based LLM judges that output scores + flags + **evidence-linked rationales**.
- Run a standardized “vanilla clinician” prompt across models to generate patient–clinician dialogues.
- Evaluate 9 “flagship” models across **366 AI patients** and **7,097 conversations** (34 clinical scenarios claimed in intro).

## What are the key metrics?

- Primary: per-dimension rubric scores (1–4) across **105 dimensions**.
- Additional: judge-produced **flags** and evidence-linked rationales (useful as qualitative error analysis signals).

## What are the main results?

- Across all evaluated models, performance is **low on many dimensions**, especially **differential diagnosis** (called out in the abstract).
- Demonstrates feasibility of scaling OSCE-like, competency-aligned evaluation with simulated patients + LLM judges.

## How is this similar to GALILEO?

- Same broad theme: **multi-turn evaluation** where dynamics and interaction quality matter more than one-shot QA.
- “LLM-as-judge with rubrics” parallels the broader evaluation ecosystem GALILEO likely needs to situate itself within.
- Emphasizes **fine-grained, decomposed dimensions** rather than a single aggregate score.

## How is this different from GALILEO?

- Domain-specific: focused on **medical patient–clinician** dialogue (process/communication/safety/outcomes), not generic social-pressure robustness / belief drift.
- Uses a high-dimensional competency rubric, but does not (from abstract/intro) center **paired pressure vs neutral controls**, **time-to-failure/survival** metrics, or explicit **drift vs evidence-driven revision** separation.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO explicitly isolates *pressure-driven drift* vs *evidence-driven revision*, that’s a clearer causal story than rubric-only scoring.
- If GALILEO reports trajectory dynamics (flip timing, recovery), it can provide more mechanistic insight than per-dimension averages.

## Where GALILEO is weaker / needs to improve

- MedPI’s **105-dimension, accreditation-aligned** rubric is a strong example of how to make evaluation feel “institutionally grounded” and interpretable to domain practitioners.
- Their committee + calibration framing for judges suggests we should be careful about judge sensitivity/bias and document calibration choices.

## Action items for GALILEO (experiments / method / writing)

- [ ] Consider adding (or at least discussing) an **OSCE/competency-style rubric decomposition** for our setting (even if smaller), to improve interpretability beyond a few scalar metrics.
- [ ] If we use LLM judges: explicitly document **judge calibration** and whether we use committees, evidence quotes, and flags.
- [ ] Add related-work positioning: “MedPI shows large-scale multi-turn evaluation pipelines in high-stakes domains; GALILEO targets robustness/drift dynamics with tighter controls.”
