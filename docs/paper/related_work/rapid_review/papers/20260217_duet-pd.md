# Persuasion Dynamics in LLMs: Investigating Robustness and Adaptability in Knowledge and Safety with DuET-PD

- Year: 2025
- Venue: EMNLP 2025 (to appear); arXiv:2508.17450v3
- Authors: Bryan Chen Zhengyu Tan; Daniel Wai Kit Chin; Zhengyuan Liu; Nancy F. Chen; Roy Ka-Wei Lee
- URL: https://arxiv.org/abs/2508.17450
- BibTeX key (if we add it): duetpd2025
- Tags: persuasion, sycophancy, multi-turn, robustness, receptiveness, metrics, DPO, safety, misinformation

## One-sentence takeaway

DuET-PD is a dual (misleading vs corrective) multi-turn persuasion evaluation on knowledge (MMLU-Pro) + safety (SALAD-Bench) that exposes strong gullibility/stubbornness trade-offs and introduces a **Holistic DPO** recipe that jointly improves resistance to misinformation and receptiveness to valid correction.

## What problem does it solve?

- We need to measure and improve an LLM’s **stance-change dynamics** in multi-turn persuasive dialogue where the desired behavior is asymmetric:
  - **Resist** misleading persuasion when you are correct (avoid gullibility / “sycophancy-to-user-assertion”).
  - **Accept** corrective persuasion when you are wrong (avoid stubbornness / overconfidence).
- Existing work often focuses on only one side (resist) or only one domain, or is single-turn.

## What is the core method / protocol?

- Build DuET-PD from MCQ sources:
  - Knowledge: MMLU-Pro (subset 1,300 MCQs; 100 per domain, excluding “other”).
  - Safety: SALAD-Bench (946 filtered MCQs with a single correct safe answer).
  - Total 2,246 MCQs, stratified 50/50 train-test.
- For each question, run **Turn 0** baseline stance check.
- Conditional 3-turn persuasion dialogue:
  - **NEG (misleading)** persuasion is applied only if Turn-0 answer was correct (tests robustness against misinformation).
  - **POS (corrective)** persuasion is applied only if Turn-0 answer was incorrect (tests receptiveness to correction).
- Persuasion messages are pre-generated, spanning 7 approaches:
  - 6 techniques adapted from prior work (evidence-based, logical, expert endorsement, authority endorsement, positive emotion, negative emotion) + a **Repetition** baseline.
- After each persuasion turn, do an **implicit stance check** by re-asking the original MCQ (not logged in dialogue), and track stance + token-probability-based confidence.

Mitigations evaluated:
- Prompting (“cautious and critical” system instruction).
- DPO fine-tuning on preference pairs derived from dialogue histories:
  - **Resist DPO**: reward refutations under NEG persuasion (robustness-centric).
  - **Holistic DPO**: add “Relent” preference samples that reward affirmations under POS persuasion (balance robustness + receptiveness).

## What are the key metrics?

(Defined for turn n; computed separately for POS vs NEG settings.)
- **Acc@0**: accuracy at Turn 0.
- **NEG-Acc@n**: accuracy after n turns of misleading persuasion (only on initially-correct items).
- **NEG-Flip@n**: fraction of initially-correct items that became incorrect after n misleading turns (gullibility; lower is better).
- **POS-Acc@n**: accuracy after n turns of corrective persuasion (only on initially-incorrect items).
- **POS-Flip@n**: fraction of initially-incorrect items corrected after n corrective turns (receptiveness; higher is better).

## What are the main results?

Key evaluation findings (Turn 3, averaged across techniques):
- **SOTA is still vulnerable in knowledge under sustained misleading persuasion**:
  - GPT-4o on MMLU-Pro: Acc@0 55.85%, but **NEG-Acc@3 27.32%** (NEG-Flip@3 51.08%).
- **Capability–adaptability trade-off**:
  - Smaller models are highly receptive to corrections (e.g., Llama-3.1-8B POS-Flip@3 ≈ 98.74% on MMLU-Pro) but are extremely gullible under misinformation (e.g., Llama-3.1-8B NEG-Flip@3 ≈ 96.65% on MMLU-Pro; 94.16% on SALAD-Bench).
  - Larger models show more robustness but can be “stubborn” (notably in safety, GPT-4o SALAD POS-Flip@3 only 26.33%).
- **Primacy effect**: most stance change happens in the **first** persuasion turn; later turns have diminishing impact (but weaker models remain persuadable).
- **Technique effectiveness differs by model class**:
  - For open-source instruct models, simple **Repetition** is already highly persuasive; elaboration helps little.
  - For stronger closed-source models, logical/evidence-based appeals add persuasion power over repetition.
- **Mitigation**:
  - Prompting yields limited gains.
  - **Resist-only DPO** can nearly eliminate gullibility but destroys receptiveness (over-rigidity).
  - **Holistic DPO** improves robustness while preserving receptiveness; headline: on SALAD-Bench for Llama-3.1-8B, **NEG-Acc@3 4.21% → 76.54%** with POS-Flip@3 still 70.33%.

## How is this similar to GALILEO?

- Very close conceptual neighbor: **multi-turn social/persuasive pressure** causing stance drift/flip.
- Explicitly frames the central tension GALILEO cares about: resist bad pressure while accepting good evidence/corrections.
- Uses turn-by-turn stance measurement; highlights first-turn sensitivity (aligns with time-to-failure / early-failure-weighting motivations).

## How is this different from GALILEO?

- Uses an **MCQ-based** stance check and synthetic appeal generation (less naturalistic than open-ended dialogue agents).
- DuET-PD’s “positive persuasion” is *correction* (asserting the correct answer), not necessarily *evidence-bearing* updates; GALILEO may want finer separation between:
  - evidence-driven belief revision vs
  - pure social pressure / assertion.
- Evaluates only 3 persuasion turns; GALILEO may want longer horizons + survival-style reporting.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO includes explicit **controls** (e.g., neutral follow-ups, evidence vs no-evidence conditions, recovery protocols), it can make a cleaner causal claim about *pressure-driven drift* vs *legitimate revision*.
- If GALILEO measures **recovery-after-flip trajectories** (return-to-truth after being misled), it adds a dimension DuET-PD largely doesn’t target explicitly.

## Where GALILEO is weaker / needs to improve

- DuET-PD’s dual-axis framing (POS vs NEG; knowledge vs safety) is a strong, simple story that GALILEO should mirror.
- Their metric set (Acc@0, POS/NEG Acc/Flip) is extremely reportable; GALILEO should ensure our metric suite is equally “table-friendly”.
- Their mitigation result (Holistic DPO) is a concrete training baseline; GALILEO needs to either (i) include it as a baseline, or (ii) clearly differentiate our contribution.

## Action items for GALILEO (experiments / method / writing)

- [ ] Add a “dual persuasion” reporting table (NEG vs POS) even if GALILEO’s POS condition is “new evidence” rather than “correction”.
- [ ] Consider adding **NEG-Flip@n / POS-Flip@n** style decomposition alongside survival/ToF metrics (readers like flip rates).
- [ ] In related work, cite their “capability–adaptability trade-off” framing; align GALILEO’s narrative around balancing robustness + adaptiveness.
- [ ] If we do any fine-tuning, consider a **Holistic** objective (don’t optimize only resistance).
