# OctoNav: Towards Generalist Embodied Navigation

- Year: 2025
- Venue: arXiv
- Authors: Chen Gao, Liankai Jin, Xingyu Peng, Jiazhao Zhang, Yue Deng, Annan Li, He Wang, Si Liu
- URL: https://arxiv.org/abs/2506.09839
- BibTeX key (if we add it): octonav2025
- Tags: embodied navigation, generalist agent, multimodal instructions, think-before-action, chain-of-thought, VLA, GRPO, online RL

## One-sentence takeaway

Proposes **OctoNav-Bench** (free-form multimodal navigation instructions + trajectories, incl. “think-before-action” CoT) and **OctoNav-R1** (an MLLM-based VLA policy trained via SFT→GRPO→online RL) to move toward *generalist* embodied navigation across task types.

## What problem does it solve?

- Embodied navigation research is fragmented across tasks (ObjNav / ImgNav / VLN / etc.), each with its own benchmarks and methods.
- They target a more **unified/generalist** setting where an agent follows **free-form instructions** combining multiple modalities and “capabilities”.

## What is the core method / protocol?

- **OctoNav-Bench**: a large-scale benchmark in continuous environments built via an (apparently) automatic annotation pipeline.
  - Provides **instruction–trajectory pairs** for imitation learning.
  - Adds a **Think-Before-Action (TBA-CoT)** dataset: textual “thinking process behind actions” aligned to trajectories.
- **OctoNav-R1**: an MLLM adapted into a **VLA-type** model that outputs low-level actions from 2D visual observations.
- **Hybrid Training Paradigm (HTP)** (3 stages):
  1) **Action-SFT + TBA-SFT** (cold-start using trajectories + TBA-CoT)
  2) **Nav-GRPO** (to improve “thinking-before-action” behavior; inspired by o1 / DeepSeek-R1-style training)
  3) **Online RL** (final performance improvements; task-specific rewards)

## What are the key metrics?

- Not extracted in detail from the skim; paper indicates **accuracy breakdown across navigation capabilities** and overall benchmark performance comparisons.
- Likely standard navigation success-style metrics (success rate / SPL / etc.) plus capability-wise accuracy (per Fig. 1 description).

## What are the main results?

- Claims **OctoNav-R1 outperforms prior methods across all capabilities** on OctoNav-Bench (per abstract + Fig. 1 description).
- Shows a **preliminary sim2real** robot demo (appendix indicates a real-world deployment section).

## How is this similar to GALILEO?

- Mostly **not** a direct neighbor if GALILEO is about multi-turn social pressure / belief drift.
- The closest conceptual link is the emphasis on **reasoning traces prior to committing to actions** (“think-before-action”), which rhymes with “think-before-answer” and could be conceptually analogous to “deliberate before yielding” dynamics.

## How is this different from GALILEO?

- Domain: **embodied navigation** and action prediction in continuous environments (vs. dialogue pressure / belief revision evaluations).
- Primary contribution is **benchmark + training recipe** for a VLA policy, not an evaluation protocol for persuasion/sycophancy.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO’s SSOT is social-pressure-induced drift, GALILEO likely has cleaner *controls* (pressure vs evidence) and clearer multi-turn stability metrics than this navigation-focused work.

## Where GALILEO is weaker / needs to improve

- If GALILEO ever extends to agentic/action domains, this paper is a reminder that **trajectory-aligned “reasoning before action” supervision** can be packaged as a dataset and used as a cold-start for RL-style improvement.
