# VCB Bench: An Evaluation Benchmark for Audio-Grounded Large Language Model Conversational Agents

- Year: 2025
- Venue: arXiv
- Authors: Jiliang Hu, Wenfu Wang, Zuchao Li, Chenxing Li, Yiyang Zhao, Hanzhao Li, Liqiang Zhang, Meng Yu, Dong Yu
- URL: https://arxiv.org/abs/2510.11098
- BibTeX key (if we add it): Hu2025VCBBench
- Tags: audio, voice-agents, evaluation, benchmark, chinese, robustness, instruction-following

## One-sentence takeaway

VCB Bench is a Chinese, real-human-speech benchmark for evaluating end-to-end voice conversational agents (LALMs) across instruction following, knowledge, and robustness.

## What problem does it solve?

- Existing audio/voice-agent benchmarks are often English-centric, rely heavily on synthetic (TTS) speech, and/or adapt text QA sets that do not stress realistic multi-turn voice conversation.
- Lack of discriminative, multi-axis evaluation (instruction adherence + knowledge + robustness) for Chinese voice chat settings.

## What is the core method / protocol?

- Constructs **VCB Bench**, a benchmark built from **authentic human recordings** (not synthetic).
- Evaluates LALMs along 3 axes:
  - **Instruction Following**
    - Text Instruction Following (TIF): continuation/creation/empathy/recommendation/rewriting/safety/simulation
    - Speech Instruction Following (SIF): emotion/language(non-dialect)/non-verbal/pacing/style/volume control
    - Multi-turn Dialog (MTD): progression/backtracking/transition over 3–5 turns
  - **Knowledge**: general knowledge across 12 domains + math/logic + discourse comprehension + story continuation
  - **Robustness**: perturbations in (i) content (mispronunciation/grammar errors), (ii) environment (noise like street/TV), (iii) speaker traits (age/accents), plus some extreme cases via post-processing (e.g., volume/speed/unstable signal)
- Dataset sources (high level): third-party professional recordings; variety-show Q&A segments (for GK); internal two-person dialogue dataset (for discourse comprehension tasks).

## What are the key metrics?

- The paper reports task/module-level benchmark results for multiple representative LALMs under unified settings (details not fully captured from abstract/skim).
- Practical metric takeaway: **module-wise scores** for instruction-following/knowledge/robustness that expose model gaps (rather than a single aggregate).

## What are the main results?

- Representative LALMs show **notable performance disparities**, suggesting current models are far from saturated on realistic Chinese voice conversation.
- The benchmark highlights weaknesses specifically in **speech-level control** (paralinguistic instruction following) and **robustness to real-world perturbations**.

## How is this similar to GALILEO?

- Both emphasize **rigorous evaluation** rather than only building a model/system.
- The multi-axis framing (capability + robustness + instruction following) is aligned with how a real conversational agent should be assessed.

## How is this different from GALILEO?

- VCB Bench is an **evaluation benchmark** for Chinese voice chat bots (end-to-end speech in/out), not a method for improving an agent.
- Focus is heavily on **Chinese + real speech recordings** and speech-level controllability (emotion/speed/volume/style), which may be outside GALILEO’s current evaluation set depending on modality.

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO targets broader scientific rigor (e.g., explicit protocols, ablations, reproducible pipelines across tasks), it can position itself as methodology-first and benchmark-agnostic.
- If GALILEO includes stronger causal analysis / calibrated uncertainty / systematic human evaluation design, that would complement VCB Bench’s dataset-driven evaluation.

## Where GALILEO is weaker / needs to improve

- If GALILEO evaluates voice agents, it likely needs more **real-speech** (not TTS) coverage and explicit stress tests for **environmental noise + speaker variation**.
- May need explicit evaluation of **paralinguistic control** (emotion, pace, volume) and **multi-turn instruction tracking**.

## Action items for GALILEO (experiments / method / writing)

- [ ] Add/expand a robustness suite that varies (speaker, environment noise, content perturbations) for any audio-grounded conversational evaluations.
- [ ] Include at least one task that tests **speech-level control** (style/emotion/pacing/volume) or explicitly document why it is out-of-scope.
- [ ] When writing related work, explicitly contrast **real human speech** benchmarks vs TTS-based evaluations and clarify what realism buys (distribution shift, noise, accents, etc.).
