# Debiasing Reward Models by Representation Learning with Guarantees

- Year: 2025
- Venue: arXiv
- Authors: Patrick Blöbaum; Siddharth Bhandari; Kun Zhang; Shiva Kasiviswanathan
- URL: https://arxiv.org/abs/2510.23751
- BibTeX key (if we add it): bloebaum2025debiasing
- Tags: reward-model, RLHF, debiasing, spurious-correlation, causal-representation-learning, invariance, sycophancy-adjacent

## One-sentence takeaway

Cast reward-model bias as *spurious latent-variable dependence* and learn a (subspace-identifiable) bias-free representation via variational inference, then train the reward model on that representation for counterfactual invariance/robustness.

## What problem does it solve?

- RLHF reward models latch onto spurious correlates (length bias, discrimination bias, sycophancy, concept/keyword shortcuts), enabling reward hacking / misgeneralization.
- Need a general (not ad-hoc per-bias) mitigation approach with some theoretical backing.

## What is the core method / protocol?

- Model observations (e.g., prompt-response text) as generated by an invertible mixing function from latent variables partitioned into:
  - spurious latent variables (dependent on a spurious attribute/surrogate S, like length / concept presence), and
  - non-spurious ("bias-free") latent variables Z_C independent of S.
- Prove *subspace identifiability* of Z_C under assumptions, in two regimes:
  - S known (have a surrogate signal for spurious attribute), and
  - S unknown (no surrogate; identifiability relies on "sufficient diversity" in what annotators rely on).
- Practical algorithm: use variational inference to recover Z_C (up to invertible transformation) and train the reward model on this representation, aiming for counterfactual invariance to S.

## What are the key metrics?

- Robustness of reward model under spurious shifts (synthetic + real text settings).
- Reduction of reliance on spurious signals (e.g., less correlation of reward with length / concepts), while maintaining preference-prediction accuracy.
- (Implied) downstream robustness to reward hacking / misgeneralization.

## What are the main results?

- Synthetic + real-world text experiments: learned approach mitigates spurious-correlation failures and yields more robust reward models than baselines that train directly on observed text features.
- Provides formal identifiability guarantees (subspace) for the bias-free latent variables in both surrogate-known and surrogate-unknown settings.

## How is this similar to GALILEO?

- Directly targets a key failure mode adjacent to GALILEO’s focus: reward-model/feedback-induced misgeneralization (length bias, sycophancy, shortcut learning), which can destabilize multi-turn behavior.
- Emphasizes invariance/robustness under distribution shifts driven by spurious features.

## How is this different from GALILEO?

- Primarily a *representation learning + theory* paper for debiasing reward models, not a multi-turn protocol/evaluation specifically about pressure/persuasion dynamics.
- Assumes a latent-variable generative model + identifiability conditions; GALILEO (as framed) seems more like a behavioral robustness framework across turns (belief revision vs drift control).

## Where GALILEO is stronger / cleaner (if true)

- If GALILEO’s contribution is an evaluation/protocol for multi-turn stability under pressure, this paper does not offer that; it focuses on reward-model training robustness.
- GALILEO can likely define operational multi-turn failure modes more concretely than latent identifiability assumptions.

## Where GALILEO is weaker / needs to improve

- If GALILEO uses reward models / preference signals anywhere, it may need a principled story for *removing spurious correlates* (length/sycophancy/concept cues) rather than only measuring downstream behavior.
- GALILEO may benefit from adopting (or rebutting) the counterfactual invariance framing: what variables should remain invariant across pressure/persuasion conditions?

## Action items for GALILEO (experiments / method / writing)

- [ ] If GALILEO trains any evaluator, add a baseline inspired by this work: learn an invariant representation (or adversarially remove spurious signals) before reward modeling, and compare multi-turn stability.
- [ ] Writing: cite their causal/identifiability framing to motivate why naive preference modeling can be unstable across turns (spurious latents shift with context/pressure).

## Quotes / details to potentially cite

- Paper motivation lists common spurious correlations in reward models: "response length, discrimination, sycophancy, and conceptual bias" (Abstract/Intro).
- Key claim: non-spurious latent variables can be identified "regardless of whether a surrogate for the spurious latent variables is available" (Abstract).
- Introduces counterfactual invariance perspective: reward model trained on Z_C should be invariant to interventions on S (Sec. 3.1 discussion).
